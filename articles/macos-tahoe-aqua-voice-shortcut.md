## 現象

macOS Tahoe 26.2 にアップデートしたところ、**Aqua Voice のグローバルショートカットキーが反応しなくなりました**。

Raycast など他のアプリのショートカットは正常に動作していたため、Aqua Voice 固有の問題かと思いましたが、調べてみると macOS のセキュリティ設定に起因する問題でした。

## 原因

macOS のアップデート時に、**入力監視（Input Monitoring）の許可がリセット**されることがあります。

Aqua Voice のようなグローバルショートカットを使うアプリは、キーボード入力を監視する権限が必要です。この権限がアップデートで外れてしまうと、ショートカットが効かなくなります。

## 解決方法

1. **システム設定** を開く
2. **プライバシーとセキュリティ** → **入力監視** を選択
3. **Aqua Voice** がリストにあるか確認
   - ある場合：一度オフにしてからオンにする
   - ない場合：`+` ボタンから Aqua Voice を追加
4. アプリを再起動

これでショートカットが復活するはずです。

## 補足

### 他のアプリでも同様の問題が起きる可能性

グローバルショートカットを使う以下のようなアプリでも同じ現象が起きる可能性があります：

- Karabiner-Elements
- BetterTouchTool
- Keyboard Maestro
- その他の入力監視を必要とするアプリ

macOS をアップデートした後にショートカットが効かなくなったら、まず **入力監視** の設定を確認してみてください。

### なぜ Raycast は動いたのか

Raycast が正常に動作していた理由として考えられるのは：

- アクセシビリティ権限のみで動作している
- Command キーを含むショートカットを使用している（macOS の制限を回避）
- 権限のリセット対象から外れていた
